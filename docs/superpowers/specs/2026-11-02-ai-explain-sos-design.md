# ИИ-памятка о лекарстве, кнопка «Мне плохо», повтор напоминания — дизайн

Утверждено автором 2026-11-02 («давай»), после исследования
`/home/Bakhtiyar/reports/ИИ помощники для приёма лекарств.md`.

## Зачем

Инструкцию к лекарству (10+ страниц) никто не читает. Пациенту, особенно
пожилому, нужно коротко: зачем лекарство, как пить, кому нельзя, что делать при
пропуске и что будет, если бросить. Лидеры рынка (Medisafe, MyTherapy, Apple)
такого не дают; LLM без опоры на инструкцию опасны (до 22 % проблемных ответов
потенциально вредны). Поэтому ИИ только **пересказывает официальную инструкцию
НЦЭЛС**. Экстренная кнопка и повтор напоминания — то, что по исследованиям
реально помогает, без ИИ.

## 1. «Коротко о лекарстве»

- Источник: госреестр НЦЭЛС, открытый API `https://register.ndda.kz/register/api/v1/PharmaRegister`:
  `POST /list` с `{"tradeName": "<название>"}` → записи (`id`, `drugTradeName`, `regNumber`, `mnn`, …);
  `GET /getRegisterInstructionFile?registerId=<id>&lang=ru` → DOCX инструкции (текст из `word/document.xml`).
- Генерация: Claude API (`claude-opus-5-5`, Go SDK), structured output, один раз на
  лекарство справочника, кэш в Postgres. Ключ — env `ANTHROPIC_API_KEY` (на Render —
  скрытая переменная). Без ключа функция молча выключена.
- Памятка (JSON, все тексты на русском, коротко, простыми словами):
  `purpose`, `how_to_take`, `do_not_take_if[]`, `missed_dose`, `if_stopped_early`,
  `urgent_signs[]`, `high_risk`, `source{title, reg_number, url}`.
- Только из текста инструкции; чего там нет — «В инструкции не указано, спросите
  врача или фармацевта». Никаких дозировок сверх инструкции.
- Группы высокого риска (инсулин, варфарин и др. антикоагулянты, противоэпилептические,
  гормональные контрацептивы, метотрексат, иммунодепрессанты, противоопухолевые,
  противопаркинсонические): `high_risk=true`, `missed_dose` = «Не принимайте пропущенную
  дозу самостоятельно — позвоните врачу». Определяется в коде по МНН/АТХ, не моделью.
- Если в инструкции нет совета о пропуске и лекарство не высокого риска, код (не модель)
  дописывает: «Не принимайте двойную дозу, чтобы восполнить пропущенную.» (поправка
  2026-11-02 по итогам ревью; правило безопасно для любого лекарства).
- Запись реестра должна совпадать по МНН с `medicines.active_substance`, иначе памятки нет
  (лучше никакой, чем о другом препарате).
- Пометка в интерфейсе: «Сгенерировано ИИ по инструкции НЦЭЛС (рег. № …). Не заменяет
  совет врача» (закон РК об ИИ, 2026).
- Где видно: приложение — кнопка «Коротко о лекарстве» у лекарства (памятка приходит в
  рецепте, работает офлайн); веб врача — блок под лекарством на странице рецепта.
- Генерация: фоновой горутиной при старте для всех лекарств справочника без памятки;
  при запросе рецепта — то, что уже есть (не ждать модель в запросе пациента).

## 2. «Мне плохо»

- Кнопка на «Сегодня» (вторичная, заметная, не акцентная заливка — акцент остаётся
  у «Выпил»): подтверждение «Позвонить в скорую 103?» → `tel:103` и одновременно
  `POST /api/sos` → push всем родственникам пациента: «<ФИО> нажал(а) «Мне плохо»» /
  «Позвоните, узнайте, всё ли в порядке». Без сети звонок всё равно идёт.
- Ниже мелко: «112 — единая служба · 9103 — скорая в Алматы, если 103 не проходит».
  Номер токсикоцентра не выдумывать.

## 3. Повтор напоминания

- Через 30 мин после приёма, если «Выпил» не нажат, — второе локальное уведомление
  («Напоминание: …», те же кнопки). Через 60 мин — push родственнику (уже есть).

## Не делаем

Свободный ИИ-чат; проверку взаимодействий; профиль и «своё лекарство» (позже).

## Решения Claude

- Модель `claude-opus-5-5` (по умолчанию навыка claude-api); ~30 памяток ≈ $2.
- Выбор записи реестра для названия: точное совпадение торгового названия без «®»
  и регистра, иначе первое с файлом инструкции; не нашли — памятки нет, кнопка скрыта.
- SOS не чаще раза в 2 минуты с одного устройства (защита от двойного нажатия).

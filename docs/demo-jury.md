# Демо-рецепты для жюри

Пять готовых рецептов в аккаунте врача `doctor1` / `doctor123`
(https://erecept.onrender.com/login → «Мои рецепты»). У каждого свой QR-код:
откройте рецепт, отсканируйте QR телефоном в приложении «еРецепт» или обычной
камерой (откроется читаемая версия рецепта).

Схемы — типичные для взрослых и только для демонстрации, это не медицинская
рекомендация. У всех лекарств есть ИИ-памятка «Коротко о лекарстве» по
инструкции НЦЭЛС.

## Что показать на каждом

- **Ангина / бронхит** — антибиотик плюс напоминания о воде. Если в инструкции чего-то
  нет, памятка честно пишет «В инструкции не указано, спросите врача или фармацевта» —
  ИИ ничего не придумывает (хороший момент показать жюри).
- **Гипертония** — пожилой пациент, три лекарства утром и вечером; повтор
  напоминания через 30 минут и push родственнику при пропуске.
- **Диабет** — приём «во время еды»; статистика соблюдения у врача.
- **Гастрит** — «до еды» и разное время (07:30); поиск Омепразола по аптекам
  и аналог «Омез» с пометкой «Согласуйте замену с врачом или фармацевтом».

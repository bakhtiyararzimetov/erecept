# еРецепт — электронные рецепты с контролем приёма лекарств

**Демо:** https://erecept.onrender.com · вход для врачей и аптек: https://erecept.onrender.com/login

## Проблема

Врачи пишут рецепты от руки, почерк непонятный. Пациенты забывают пить лекарства
и не знают, где купить дешевле.

## Решение

1. Врач заполняет рецепт на веб-странице, система генерирует QR-код.
2. Пациент сканирует QR в мобильном приложении, и оно само строит расписание приёма.
3. Приложение напоминает о лекарствах и воде, пациент нажимает «Выпил». Если не
   отметил за 60 минут — уведомление родственнику.
4. Пациент находит лекарство в аптеках и сравнивает цены.
5. Врач видит, насколько пациент соблюдает лечение.

## Демо-учётки

| Роль | Логин | Пароль |
|---|---|---|
| Врач | `doctor1` (Ахметова Динара Сериковна, Поликлиника №5) | `doctor123` |
| Врач | `doctor2` (Ким Александр Петрович, Городская поликлиника №12) | `doctor123` |
| Аптека | `apteka1` … `apteka8` | `apteka123` |

Тестовые данные (2 врача, 8 аптек в Алматы, 30 лекарств с разными ценами)
загружаются автоматически при первом запуске, если база пустая.

## Сценарий показа (5 минут)

Готовые демо-рецепты на 5 болезней: [docs/demo-jury.md](docs/demo-jury.md).

1. **Врач.** Откройте `/login`, войдите как `doctor1`. Заполните пациента, добавьте
   2 лекарства кнопкой «+ Добавить лекарство», включите «Воду» каждые 2 часа.
   «Сохранить рецепт» → справа QR-код, кнопка «Распечатать рецепт».
2. **Пациент.** В приложении «Сканировать рецепт» → наведите камеру на QR
   (или введите код вручную). На экране «Сегодня» появится расписание.
3. **Напоминание.** Придёт уведомление «Парацетамол — 1 таблетка 500 мг, после еды ·
   день 1 из 5» с кнопками «Выпил» и «Через 15 мин». Работает без интернета.
4. **Где купить.** Вкладка «Аптеки»: список аптек с ценой, адресом и часами,
   сортировка по цене или расстоянию, «На карте». Аналоги — с пометкой
   «Согласуйте замену с врачом или фармацевтом».
5. **Родственник.** «Настройки» → «Пригласить родственника» → 6-значный код.
   На втором телефоне «Я родственник — ввести код».
6. **Статистика.** Врач открывает рецепт: «Соблюдение лечения» — процент, отмечено,
   пропущено, впереди.
7. **Аптека.** Войдите как `apteka1`: цены и наличие вручную или загрузкой CSV.
8. **Коротко о лекарстве (ИИ).** У лекарства в приложении — «Коротко о лекарстве»:
   зачем, как принимать, кому нельзя, что делать при пропуске, когда срочно к врачу.
   Тот же текст врач видит на странице рецепта.
9. **«Мне плохо».** Кнопка на экране «Сегодня»: звонок в 103 и push родственнику.

## ИИ-памятка о лекарстве

Инструкцию на 10+ страниц никто не читает, поэтому приложение показывает короткую
памятку. ИИ не придумывает её сам, а **пересказывает официальную инструкцию**:

1. Сервер находит лекарство в госреестре НЦЭЛС (`register.ndda.kz`), проверяет, что
   действующее вещество совпадает, и скачивает утверждённую инструкцию.
2. Claude (`claude-opus-5-5`) пересказывает её по фиксированному шаблону: «Зачем»,
   «Как принимать», «Кому нельзя», «Если пропустили приём», «Если бросить раньше»,
   «Срочно к врачу». Чего нет в инструкции — «В инструкции не указано, спросите врача
   или фармацевта».
3. Правила безопасности задаёт код, а не модель:
   - для опасных групп (инсулин, варфарин, противоэпилептические, контрацептивы,
     иммунодепрессанты и др.) при пропуске — «позвоните врачу»;
   - всегда «двойную дозу не принимайте»;
   - «Дозу назначил врач — принимайте как в рецепте».
4. Памятка генерируется один раз на лекарство и хранится в базе, поэтому
   приложение показывает её мгновенно и без интернета.
5. Внизу пометка «Сгенерировано ИИ по инструкции НЦЭЛС, рег. № … Не заменяет совет
   врача» — этого требует закон РК об ИИ.

Без переменной `ANTHROPIC_API_KEY` функция выключена, остальное работает.
Свободного ИИ-чата нет намеренно: исследования показывают, что ответы LLM о
лекарствах без опоры на инструкцию бывают опасны.

## «Мне плохо» и повтор напоминания

- «Мне плохо» на экране «Сегодня»: подтверждение → звонок в 103 и одновременно push
  всем родственникам («… нажал(а) «Мне плохо»»). Без интернета звонок всё равно
  идёт. Ниже подсказка: 112 — единая служба, 9103 — скорая в Алматы.
- Если «Выпил» не нажали, через 30 минут приходит повторное напоминание, через 60 —
  push родственнику.

## Архитектура

```
 Врач / аптека (браузер)          Пациент / родственник (Expo)
          │ HTML + htmx                      │ REST JSON, X-Device-Secret
          ▼                                  ▼
 ┌──────────────────── Go-сервер (chi) ────────────────────┐
 │ internal/web   страницы врача и аптеки, QR, печать      │
 │ internal/api   REST API для приложения                  │
 │ internal/notifier  раз в минуту: пропуски → Expo Push    │
 └──────────────────────────┬──────────────────────────────┘
                            ▼
                       PostgreSQL
```

- **Бэкенд:** Go, chi, PostgreSQL + pgx, миграции — SQL-файлы в
  `internal/db/migrations`, QR — skip2/go-qrcode, пароли — bcrypt,
  часовой пояс Asia/Almaty.
- **Веб врача и аптеки:** html/template + htmx, без React. Шаблоны и CSS встроены
  в бинарник.
- **Приложение:** React Native + Expo (SDK 58), TypeScript, expo-router,
  expo-camera, expo-notifications (локальные), AsyncStorage.
- **Пациент без логина:** приложение создаёт случайный секрет устройства и шлёт его
  в заголовке `X-Device-Secret`.
- **QR** содержит ссылку `<адрес>/r/<код>`: обычная камера откроет читаемый рецепт
  (удобно в аптеке), приложение берёт из ссылки код.

## Структура

```
cmd/app/main.go         запуск сервера, миграции, автозагрузка тестовых данных
cmd/seed/main.go        ручная загрузка тестовых данных
internal/db             подключение, миграции, dbtest (Postgres для тестов)
internal/models         структуры таблиц, генерация расписания приёмов
internal/seed           2 врача, 8 аптек, 30 лекарств
internal/web            страницы врача и аптеки (templates/, static/)
internal/api            REST API для приложения
internal/notifier       push родственнику при пропуске
mobile/                 Expo-приложение (app/ — экраны, lib/ — логика)
```

## Запуск локально

### Сервер через Docker

```bash
cp .env.example .env
docker compose up --build
```

Откройте http://localhost:8080/login.

### Сервер без Docker

Нужен Postgres. Укажите его в `DATABASE_URL` в `.env`, затем:

```bash
go run ./cmd/app
```

### Приложение

```bash
cd mobile
npm install
npx expo start
```

Отсканируйте QR из терминала приложением **Expo Go** на телефоне. По умолчанию
приложение работает с https://erecept.onrender.com. Чтобы подключить локальный
сервер, укажите адрес компьютера в сети:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.10:8080 npx expo start
```

## Переменные окружения

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `DATABASE_URL` | строка подключения к Postgres | — (обязательна) |
| `PORT` | порт сервера | `8080` |
| `TZ` | часовой пояс | `Asia/Almaty` |
| `PUBLIC_URL` | адрес, который зашивается в QR | `RENDER_EXTERNAL_URL` или адрес запроса |
| `SEED_DEMO` | `0` — не загружать тестовые данные | загружать, если база пустая |
| `KEEP_AWAKE_HOURS` | часы самопинга на Render | `8-23` |
| `ANTHROPIC_API_KEY` | ключ Claude API для ИИ-памяток | пусто — памятки выключены |

## Загрузка цен аптекой (CSV)

Разделитель `;` или `,`, первая строка — заголовок:

```
название;действующее вещество;форма;цена;наличие
Парацетамол;парацетамол;таблетки 500 мг №20;350;да
Нурофен;ибупрофен;таблетки 200 мг №10;1 250 ₸;нет
```

Цена — целое число в тенге (пробелы и «₸» допускаются). Наличие: да / есть / 1 или
нет / 0. Пример файла можно скачать в кабинете аптеки.

## Push родственнику

Сервер раз в минуту ищет приёмы, не отмеченные за 60 минут, и шлёт push через
Expo Push API. Для push нужен Expo push-токен, а он доступен только в сборке
приложения через EAS (в Expo Go на Android удалённые push не работают):

```bash
cd mobile
npx eas login
npx eas init          # добавит projectId в app.json
npx eas build --profile development --platform android
```

Без этого всё остальное работает, а в «Настройках» видно «Push недоступен: нужна
сборка с EAS».

## Деплой

Сервер живёт на Render (Docker, бесплатный тариф, регион Frankfurt) и
обновляется сам после каждого `git push` в `main`.

- Бесплатный сервер засыпает без запросов. Днём (08:00–23:00) он сам себя пингует,
  ночью спит, и первый запрос будит его 30–60 секунд. Перед показом откройте сайт
  заранее.
- Бесплатная база Render действует до **1 декабря 2026**.

## Дизайн

Спокойный медицинский стиль без градиентов, теней, анимаций и эмодзи. Шрифт Inter,
фон #F6F8FA, белые карточки с рамкой #E5E7EB, один акцентный цвет #0F766E для
главных кнопок. В приложении крупные кнопки (56px) и текст от 17px для пожилых
пациентов. Веб нормально выглядит и на телефоне.
